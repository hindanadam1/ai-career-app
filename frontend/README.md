# Frontend

Interface React de l'application AI Career. Les pages disponibles sont la connexion, l'inscription, le tableau de bord, la création de CV, la lettre de motivation, la préparation d'entretien et l'historique.

Depuis ce dossier :

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

Les détails de l'architecture et le lancement de l'API se trouvent dans le [README principal](../README.md).
